# 风格卡与风格库

一条剪得好的成品，拆成**一张风格卡**，存进**风格库**。以后出方案时选一张卡，让自动导演照它的写法剪。

## 流程

1. 首页或项目里点 **风格库 → 拆解新视频**，填成品的本机路径。
2. 程序只读这个文件（不复制、不修改，它的画面不会进入你的视频）：
   - ffmpeg 每秒抽一帧；
   - 场景检测找出每个硬切点（间隔不足 0.4 秒的合并成一个）；
   - 本地 Whisper 转写，带词级时间戳；
   - 把关键帧加转写文字加切点数据一起交给「API 设置」里的模型，让它写一张风格卡。
3. 卡片是**草稿**。按六栏核对、修改，起一个名字（如 `kika-UGC快节奏`），点「确认并存入风格库」。
4. 之后每拆一条新视频，风格库里多一张卡。改过已确认的卡，状态回到草稿，要重新确认。
5. 在「② 方案」选一张已确认的卡，自动导演才会按它出方案。

## 卡里有什么（`library/style-cards/<id>.json`）

| 栏 | 内容 |
| --- | --- |
| ① 结构 | 按时间分段：钩子、痛点、产品演示、证明、卖点、行动号召，每段写做了什么 |
| ② 节奏 | 平均几毫秒换一次画面、句间停顿是否全剪、允许保留的最长停顿 |
| ③ 镜头 | 是否对重点词推近、推近倍数、近景/中景是否交替 |
| ④ 字幕 | 位置、样子（颜色、描边、底色）、关键词怎么强调、出现方式、每块几个词、是否大写、是否带 emoji |
| ⑤ 插入 | 全屏/画中画/混合、第一次插画的时间、每次时长、占比、品牌图标是否常驻、结尾怎么收 |
| ⑥ 包装 | 贴纸/表情、音效、背景音乐、说话时音乐压低多少 dB。**现在只记在卡里，不进渲染**，导出剪映草稿后由你在剪映里补 |

另有：每个做法标注引擎「已支持 / 部分支持 / 暂不支持」；一组给自动导演看的英文规则（`directorRules`）。

## 卡怎么影响出方案

自动导演（`scripts/auto-director.mjs --card=<id>`）从卡里取：

- 英文规则：写进选片提示；
- 数字：每次插画最短/最长时长、第一次插画的时间，以及全屏占比上限（卡是全屏风格时）；
- 卡的插入方式不是全屏时，才允许用画中画；卡里勾了「品牌图标常驻」才允许放图标。

「全屏插画」和「极简口播」两套**不看卡**；「按风格卡」这一套完全照卡。没选卡时只出前两套。

## 已定的决定

- **时间线格式要统一成一份。** 方案表格（时间、口播、画面、效果、字幕/贴纸、音效）直接读写它，edit-plan 由它编译出来。这一步还没做，是下一步（口播清理 → 表格方案）。
- **包装栏先只记录。** 贴纸、音效、背景音乐不进渲染；导出剪映草稿时由你在剪映里补（草稿里已有自制的 whoosh/pop 音效轨，可替换）。
