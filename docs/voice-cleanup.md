# 口播清理

出方案之前，先把每条达人口播里**不该留下的东西**挑出来。页面：项目里的 **② 口播**；命令行：`node scripts/cleanup-voice.mjs <项目id> [--review]`。

## 检测什么

| 类型 | 怎么找 | 默认 |
| --- | --- | --- |
| 停顿 | ffmpeg 静音检测（-38 dB），句间停顿 ≥ 0.25 秒就剪，留 0.1 秒换气；开头和结尾的静音一起去掉 | 删 |
| 语气词 | um / uh / er / hmm | 删 |
| 重复字 | 同一个词连说两遍，删前一个 | 删 |
| 重说 | 一句话没说完又从头说了一遍（前几个词相同），或者整句连说两遍：删前一次 | 删，需你核对 |
| 口误 | 规则看不出来，由「AI 复核」按钮让模型读一遍；也可以点任意一个词手动标 | 删，需你核对 |

每一处都有「删掉」开关和 ▶ 试听。你的取舍在重新检测后会保留。**改动之后要重新点「确认清理」**，确认之前方案页不能生成。

## 为什么要重新对词的时间

Whisper 给的词时间是估计值，会把停顿摊进前一个词（实测一个词能偏 0.8 秒），所以不能直接用它来剪。程序先用音频里真正有声音的段落，把每个词按顺序、按句末标点放回对应的段落里，再在段落里按字数分配时间。确认后的 `cleanup.json` 里存的就是这些重对过的时间，后面的切点、字幕、插画位置都用它。

## 对后面的影响

- 一个镜头（beat）可以由几段保留下来的口播拼成（`voice.ranges`）；字幕和插画位置按剪掉之后的时间算。
- 被删掉的词不出现在字幕里，也不能当插画的锚点。
- 没有确认的清理时，旧项目按原来的方式剪（不受影响）。
- 确认清理之后，之前生成的方案会标「过期」，需要重新生成。

## 数据（`projects/<id>/cleanup.json`）

`clips.<素材id>`：`segments`（有声音的段落）、`timings`（每个词重对后的 [开始, 结束] 毫秒，按词序）、`edits`（每一处：类型、起止、原因、来源 auto/model/user、decision delete/keep）。
