# TikTok One 订单剪辑 SOP

给第一次接手的人看的。照着做，一条订单从拿到素材到交出成片，不需要懂代码。

**这套系统做什么**：达人把口播和动作视频发给我们，我们要剪成一条 9:16 的带货短视频。系统帮你做重复的活（转竖屏、转文字、找停顿、选录屏插在哪句话、出字幕），你负责核对、挑版本、最后把关。

---

## 0. 开始之前

### 要准备的东西

| 东西 | 说明 |
| --- | --- |
| 订单文件夹 | 从 TikTok One 下载整理好的订单，结构见下面「订单文件夹长什么样」 |
| 一台装好的电脑 | 装有 Node.js、ffmpeg、Chrome；已经按 `docs/whisper-setup.md` 装好语音转文字；要导出剪映草稿，还要装剪映专业版并按 `docs/capcut-export.md` 装好导出组件 |
| API Key | 中转站的 Key，用于让 AI 描述素材、选录屏、复核口播 |
| 一条参考成品（可选） | 剪得好的同类视频，用来做「风格卡」 |

### 订单文件夹长什么样

```
2026-10_Kika-Keyboard/
├─ 00_参考成品/        品牌或同事给的参考视频（只用来学剪法）
├─ 01_品牌要求/        品牌要求截图
├─ 02_官方素材/        品牌给的录屏、logo
├─ 03_脚本/            发给达人的脚本、brief.json（品牌要求整理结果）
├─ 04_达人回片/
│   └─ 达人1_Kelsie/
│       ├─ 01_近景_拿手机看屏幕.mov
│       ├─ 02_半身_口播A.mp4
│       └─ 03_半身_口播B.mp4
└─ 05_成品/            最后的成片放这里
```

文件名里带「近景」「半身」「口播A」这些词，系统能认出是哪一类；没有也行，后面可以在页面里改分类。

### 怎么打开

在项目文件夹里运行：

```
npm run desk
```

然后用浏览器打开 `http://127.0.0.1:4310/`。这个窗口要一直开着，关了页面就用不了。

> 改了程序之后页面没变化？关掉再重新运行 `npm run desk`。

## 1. 一次性设置（只做一次）

### 1.1 填 API Key

首页右上角进「风格库」或任意项目页，点 **API 设置**：

- 接口地址、模型默认已经填好；
- 粘贴 API Key，点「保存并测试连接」，看到绿色的"连接成功"才算好；
- Key 只保存在这台电脑上，不会进 Git。

### 1.2 做一张风格卡（有参考成品时）

风格卡 = 一条好视频的"剪法说明书"，记下它的结构、节奏、字幕样式、插画方式。

1. 首页点 **风格库 → 拆解新视频**。
2. 填参考成品的完整路径（例如订单里的 `00_参考成品\xxx.mp4`），点「开始拆解」，等 1–2 分钟。
3. 打开生成的卡，**对着原视频核对六栏**：结构、节奏、镜头、字幕、插入、包装。不对的直接改。
4. 起一个好认的名字（例如 `kika-UGC快节奏`），点 **确认并存入风格库**。

卡片是草稿时不会影响任何东西，**确认了才能用**。改过已确认的卡，要重新确认。

## 2. 每条订单的流程

页面顶部有 5 个步骤：**① 素材 → ② 口播 → ③ 方案 → ④ 精修 → ⑤ 导出**。前面没完成，后面的按钮是灰的。

### 第 0 步：导入订单素材

1. 首页点 **导入订单素材**。
2. 两种方式任选一种：
   - **拖入素材**（没有整理好的订单文件夹时用）：填产品名称，点「新建订单」，然后把素材按类别拖进五个框——达人口播、达人动作、游戏录屏、口播文本（你发给达人读的脚本，.txt 或 .md）、官方素材（logo、截图也放这里）。至少要有一条达人口播。拖错了点文件右边的 × 移除。素材会复制到项目里的 `inbox` 文件夹，原文件不动；文件夹不能直接拖，请选中里面的文件。
   - **已有订单文件夹**：填完整路径（只读，不复制）。
3. 点「开始导入」。
4. 等它跑完三步（约 1–3 分钟，4K 视频会慢一点）：
   - 把素材转成竖屏、30 帧的工作副本；
   - 把达人口播转成文字；
   - 让 AI 给每个素材写一句描述。
5. 点「进入『素材』」。

> 订单文件夹**只读**，系统不会改它。工作副本放在 `public/derived/`，文字和记录放在 `projects/<项目名>/`。

**完成标志**：进入「① 素材」页，能看到所有素材的卡片。

### ① 素材：分类、核对、确认

目标：让每个素材都"有名字、有描述、归对了类"，并把口播文字校对准。

页面上有五个分类：文案、达人口播、达人动作、游戏录屏、官方素材。

1. **看分类对不对**。每张卡片有分类下拉框，错了就改。
2. **看描述对不对**。AI 写的描述有「AI 草稿」标记，你改过会变成「已人工修改」，AI 以后不会覆盖你改的内容。想让 AI 重写，点「AI 描述」。
3. **校对口播文案**（最重要）。在「文案」分类里，每条口播一张卡片，文字是电脑听出来的，可能有错：
   - 导入时放了口播文本的话，卡片上点「对照给达人的脚本」，脚本显示在下面，达人没读到的词标橙色，多说的词列在下面；
   - 点「听对应口播」，一边听一边改；
   - **只能改拼写，不能多词或少词**。字幕的时间是按词对齐的，词数变了系统会拒绝并提示；
   - 卡片下面会列出"和电脑听写相比你改了哪些词"，改动很大的会标红，防止不小心剪切粘贴弄乱了。
4. **全部点「确认」**。卡片多的话用「确认当前列表全部」。

**完成标志**：顶部显示"已确认 13 / 13"，页面提示「去『口播清理』→」。

### ② 口播：剪掉停顿、语气词、重说

目标：把达人说话时的"死气"去掉。

1. 点 **开始检测**，约 10 秒。
2. 每条口播会显示文字，下面标出要剪的地方：
   - ⏸ 红色的是**停顿**（句子之间停太久，会留 0.1 秒换气）；
   - 红色划线的字是**语气词、重复字、重说**；
   - 每一处旁边有 ▶ 可以试听，有「删掉」开关可以改成保留。
3. 觉得漏了口误，点 **AI 复核口误和重说**，AI 会再读一遍；你也可以直接点文字里的任意一个词，把它标成要删。
4. 核对完点 **确认清理**。

> 改了任何一处，都要重新点「确认清理」。

**完成标志**：顶部显示"口播从 X 秒缩到 Y 秒"，提示「去『方案』→」。

### ③ 方案：选录屏、挑版本

目标：AI 为每句口播配画面，你比较几个版本，选一个。

**生成**

1. 页面顶部会检查四件事：口播已清理、素材已确认、模型可用、风格卡（可选）。哪一项不对，旁边有按钮直接跳过去。
2. 可以选一张风格卡。选了会多出一个"按风格卡"的版本，不选只出两个。
3. 点 **生成方案**，等约 2 分钟。AI 为每句话选录屏、定时间，程序再检查一遍（时长、重叠、占比、禁止的说法），不合格会让 AI 重来。

**比较和修改**

每个版本是一张表，一行一句口播：

| 列 | 内容 | 你能做什么 |
| --- | --- | --- |
| 时间 | 这一句在成片里的位置 | 只看 |
| 口播内容 | 这一句说什么 | 只看（要改回「① 素材」） |
| 画面 | 这一句用什么画面 | 换素材、改全屏/画中画、改位置、改开始时间和时长、加或删镜头；没插画的行显示达人画面 |
| 效果 | 推近倍数 | 自动 / 不推近 / 110% / 115% / 120% |
| 字幕 | 这句话的每个词 | 点一个词，字幕里就高亮它 |
| 音效 | 插画出现处的声音 | 自动 / 无 / 嗖 / 叮（只有导出剪映草稿才有） |

改过的行底色变黄，页面底部显示"改了 N 行，还没保存"：

- 点 **保存并更新这一套**，系统检查（不能超出这一句、两个镜头不能重叠、素材够长等），有问题会告诉你哪里不对，整次不保存；
- 想全部改成全屏或画中画，用上面的「全部全屏 / 全部画中画」；
- 想要品牌图标一直出现，勾上「常驻品牌图标」。

**选定**

选好版本，点 **选这一版 → 放进审阅精修**。如果审阅台里已经有你改过的方案，会先弹窗告诉你：会生成新版本，字幕样式和主题会保留，上一个版本还能还原。

**完成标志**：页面跳到「④ 精修」。

### ④ 精修：最后的微调

目标：在真实预览里看一遍，把细节调好。

1. 左边是片段列表，中间是预览，右边是检查和参数。
2. 可以拖字幕框的位置、改字号颜色、调镜头；画面上红色标签是平台界面区（TikTok 文案区、右侧按钮、顶部标签），**字幕和文字不要放进这些区域**。
3. 每个片段可以标「保留 / 修改 / 放弃」，也可以写意见。
4. 所有改动自动保存成新版本，在「版本」里能看到，随时可以还原。
5. 画面上有"盖住人脸""超出安全区"的警告，按需要处理；全屏录屏碰到安全区是正常的，不用管。

**完成标志**：你看完整条，觉得可以交了。

### ⑤ 导出：出成片

**方式一：直接渲染成片**

1. 在「导出中心」确认文件名，点「开始导出视频」，约 5 分钟。
2. 程序会自动质检：规格（9:16、30 帧）、响度（-16 LUFS）、字幕时间、有没有空白或冻结的画面。
3. **质检通过只是及格线，一定要自己从头看一遍、听一遍。**

**方式二：导出剪映草稿，在剪映里再加工**

适合要加音效、背景音乐、贴纸等"调味"的订单。

1. 在导出中心的「剪映草稿」，点 **生成剪映草稿**。
2. 点 **放进剪映草稿箱**（系统会自动找到你的剪映草稿位置）。
3. 打开剪映，在草稿列表里找到它（没出现就关掉重开剪映），所有切点、字幕、录屏和音效都已摆好，花几分钟微调后在剪映里导出。

> 草稿里的素材只是**指向本机文件的链接**。不要移动或改名 `public` 文件夹里的文件，否则剪映会提示"素材丢失"。

### 交付

把最终的 MP4 复制到订单的 `05_成品` 文件夹，按订单要求命名并提交。

## 3. 交付前自查清单

打勾再交：

- [ ] 画面是 **9:16 竖屏**，清晰（HD），没有模糊或马赛克
- [ ] 口播里**没有品牌不允许的说法**：不编造数字、评分、下载量、获奖；不提竞品，不做对比；不说电池、隐私、安全；没有诱导点击的箭头
- [ ] 字幕拼写正确，**位置不在平台文案区和右侧按钮区**
- [ ] 画面里没有违规内容（歧视、政治、毒品武器、成人内容、危险动作）
- [ ] 开头 2–3 秒就能抓住人（达人出镜、有钩子）
- [ ] 结尾有行动号召（例如"just get Kika"）
- [ ] 自己从头看了一遍，也听了一遍，音量正常、没有爆音
- [ ] 文件名符合订单要求，放进了 `05_成品`

## 4. 常见问题

| 现象 | 原因和办法 |
| --- | --- |
| 「生成方案」是灰的 | 看页面上的四项检查，哪项是红叉，点旁边的按钮去处理（素材没确认、口播没确认、没有 API Key） |
| 保存口播文案时提示"词数变了" | 字幕按词对齐，只能改拼写，不能增删词。点「还原」回到听写原文，再改 |
| 文案卡片上有红色的"→"提示 | 你的改动和听写差别很大，可能是剪切粘贴时弄乱了，仔细看一眼 |
| 方案上显示"过期" | 你在生成之后又改了素材、文案或口播清理。点「重新生成全部方案」 |
| AI 描述、生成方案失败，提示 401 | API Key 不对或过期，到「API 设置」重新保存并测试连接 |
| 页面改了没反应 | 关掉运行 `npm run desk` 的窗口，重新运行 |
| 剪映草稿箱里看不到刚放进去的草稿 | 关闭剪映再重新打开；还不行，看导出中心给出的草稿箱路径对不对 |
| 剪映提示素材丢失 | 工作副本被移动或改名了，不要动 `public` 文件夹 |
| 导出的视频没有音效 | 正常：网页渲染的成片不带音效，只有剪映草稿里有 |
| 想回到之前的版本 | 在「④ 精修」的「版本」里选旧版本还原，旧版本不会丢 |

## 5. 术语对照

| 词 | 意思 |
| --- | --- |
| 达人 / 回片 | 拍视频的人 / 她发回来的原始视频 |
| 口播 | 达人对着镜头说话的片段 |
| 录屏 | 手机或软件的操作画面，用来盖在口播上，也叫插画 |
| 画中画 | 录屏变成小窗口，达人依然在画面里 |
| 风格卡 | 一条好视频的剪法说明书，可以反复用 |
| 口播清理 | 剪掉停顿、语气词、重说、口误 |
| 方案 | AI 给出的一个剪法版本，每个版本一张表 |
| 版本 | 审阅台里保存的每一次修改，随时可以还原 |
| 安全区 | TikTok 界面会盖住的位置（底部文案、右侧按钮、顶部标签），字幕要避开 |

## 6. 文件放在哪里（出问题时看这里）

| 内容 | 位置 |
| --- | --- |
| 订单原始素材 | 订单文件夹（只读，不要改） |
| 转好的工作副本 | `public/derived/<项目名>/` |
| 听写文字 | `public/transcripts/` |
| 项目记录（素材、清理、方案、审阅版本） | `projects/<项目名>/` |
| 风格卡 | `library/style-cards/` |
| 剪映草稿 | `projects/<项目名>/exports/capcut/` |
| 渲染的成片 | 导出中心里显示的路径 |
| 出错日志 | `projects/<项目名>/logs/` |

更详细的说明：`docs/style-card.md`（风格卡）、`docs/voice-cleanup.md`（口播清理）、`docs/timeline-table.md`（表格方案）、`docs/capcut-export.md`（剪映草稿）。
