# TikTok One 订单剪辑 SOP

给第一次接手的人看的。照着做，一条订单从拿到素材到交出成片，不需要懂代码。

**这套系统做什么**：达人把口播和动作视频发给我们，我们要剪成一条 9:16 的带货短视频。系统帮你做重复的活（转竖屏、转文字、找停顿、选录屏插在哪句话、出字幕），你负责核对、挑版本、最后把关。

---

## 先看这一页（5 分钟看懂）

**一条订单的路线**：导入素材 → ① 素材 → ② 口播 → ③ 方案 → ④ 精修 → ⑤ 导出。页面顶部有这 5 个步骤，前面的没完成，后面的按钮是灰的。

| 步骤 | 你做什么 | 做完的标志 | 卡住了看哪里 |
| --- | --- | --- | --- |
| 导入 | 首页点「导入订单素材」，把视频按类别拖进去（至少一条达人口播），点「开始导入」 | 页面跳到「素材」，能看到所有卡片 | 失败提示里有哪一步出错；改了程序要先重启（见下） |
| ① 素材 | 核对分类和描述，把口播文字校对准（只能改拼写），逐个点「确认」 | 顶部显示"已确认 N / N" | 提示"词数变了"：点「还原」再改 |
| ② 口播 | 点「开始检测」，听一遍标红的停顿和口误，不对的改回保留，点「确认清理」 | 顶部显示"口播从 X 秒缩到 Y 秒" | 检测报错：先确认 ① |
| ③ 方案 | 点「生成方案」，比较三套（每套一个方向），选一套点「选这一版」 | 页面跳到「④ 精修」 | 全部失败：看页面上的红色说明；401 是 API Key 的问题 |
| ④ 精修 | 在预览里从头看一遍，调字幕位置和细节 | 你觉得可以交了 | 想回到旧版本：「版本」里还原 |
| ⑤ 导出 | 渲染成片，或生成剪映草稿；质检通过后自己再看、听一遍 | 成片文件和质检结果出现 | 草稿放不进剪映：先关掉剪映 |

**最容易踩的 8 个坑**

1. **改了程序之后页面没变化**：关掉运行 `npm run desk` 的窗口，重新运行。报"No route …""body too large"也是因为服务还是旧的。
2. **「素材」和「口播」没确认，「生成方案」就是灰的**：确认是你的操作，程序不会替你点。
3. **口播文字只能改拼写，不能增删词**：字幕按词对齐，词数变了系统会拒绝。
4. **拖入的素材会复制到项目里**：原文件不动，但 4K 视频会占空间。
5. **风格卡要先「确认」才能选**：草稿状态的卡在方案页的下拉框里看不到。
6. **不要移动或改名 `public` 文件夹里的文件**：剪映草稿里的素材只是指向它们的链接，动了会提示"素材丢失"。
7. **方案和剪映草稿都不带音效**：需要的话在剪映里加。
8. **质检通过只是及格线**：交付前一定自己从头看一遍、听一遍。

## 0. 开始之前

### 要准备的东西

| 东西 | 说明 |
| --- | --- |
| 订单文件夹 | 从 TikTok One 下载整理好的订单，结构见下面「订单文件夹长什么样」 |
| 一台装好的电脑 | 装有 Node.js、ffmpeg、Chrome；已经按 `docs/whisper-setup.md` 装好语音转文字；要导出剪映草稿，还要装剪映专业版并按 `docs/capcut-export.md` 装好导出组件 |
| API Key | 中转站的 Key，用于让 AI 描述素材、选录屏、复核口播 |
| 一条参考成品（可选） | 剪得好的同类视频，用来做「风格卡」 |

### 订单文件夹长什么样

```
2026-10_Kika-Keyboard/
├─ 00_参考成品/        品牌或同事给的参考视频（只用来学剪法）
├─ 01_品牌要求/        品牌要求截图
├─ 02_官方素材/        品牌给的录屏、logo
├─ 03_脚本/            发给达人的脚本、brief.json（品牌要求整理结果）
├─ 04_达人回片/
│   └─ 达人1_Kelsie/
│       ├─ 01_近景_拿手机看屏幕.mov
│       ├─ 02_半身_口播A.mp4
│       └─ 03_半身_口播B.mp4
└─ 05_成品/            最后的成片放这里
```

文件名里带「近景」「半身」「口播A」这些词，系统能认出是哪一类；没有也行，后面可以在页面里改分类。

### 怎么打开

在项目文件夹里运行：

```
npm run desk
```

然后用浏览器打开 `http://127.0.0.1:4310/`。这个窗口要一直开着，关了页面就用不了。

> 改了程序之后页面没变化？关掉再重新运行 `npm run desk`。

## 1. 一次性设置（只做一次）

### 1.1 填 API Key

首页右上角点 **API 设置**（只有首页有这个按钮）：

- 接口地址、模型默认已经填好；
- 粘贴 API Key，点「保存并测试连接」，看到绿色的"连接成功"才算好；
- Key 只保存在这台电脑上，不会进 Git。

### 1.2 做一张风格卡（有参考成品时）

风格卡 = 一条好视频的"剪法说明书"。程序量出它的节奏数字，AI 看懂每一段在做什么，整理成一张卡：**开场怎么处理、节奏快慢、插画放在哪、画中画还是全屏、怎么推近**，外加这条视频逐段的示范。

1. 首页点 **风格库 → 拆解新视频**。
2. **把成品视频拖进虚线框**（或点框选文件；也可以展开"或者填本机文件的完整路径"）。点「开始拆解」，等 1–2 分钟。
3. 打开生成的卡，按四个标签核对：
   - **概览**：方向的中文摘要、程序测出的数字（平均镜头时长、插画占比等，不用手填）、**复现度**（见下）；
   - **时间线**：这条视频被拆成哪几段，每段是达人还是插画、全屏还是画中画、推近多少，不对的直接改，保存后数字会自动重算；
   - **规则**：给自动导演的英文规则，**不能出现参考视频的产品名**；只属于那个产品的内容（比如它的功能、画面）在灰色的"只属于参考视频的内容"里，不会交给自动导演；
   - **技巧支持**：卡里用到、但渲染引擎现在还做不到的做法（贴纸、发光字幕等），首页"待开发的效果"会汇总这些。
4. 点「自测复现度」：程序用这条视频自己的口播，按这张卡出一次方案，和原视频比。"插画位置重合""推近一致"的百分比低，说明卡没写准，或者引擎缺东西。
5. 起一个好认的名字（例如 `kika-UGC快节奏`），点 **确认并存入风格库**。

卡片是草稿时不会影响任何东西，**确认了才能用**。改过已确认的卡，要重新确认。

风格库左边的三个筛选：**产品类型**（App 还是实物）、**视频形式**（单人口播、反应型、对比型、清单型、剧情型）、**节奏**（按平均镜头时长：不到 2 秒一换是快节奏，2–3 秒中速，更长是舒缓）。卡越多，越要靠筛选找。

> 一张卡只有一种剪法。想让不同订单的片子不千篇一律，风格库里最好有几张**不同形式、不同节奏**的卡。

## 2. 每条订单的流程

页面顶部有 5 个步骤：**① 素材 → ② 口播 → ③ 方案 → ④ 精修 → ⑤ 导出**。前面没完成，后面的按钮是灰的。

### 第 0 步：导入订单素材

1. 首页点 **导入订单素材**。
2. 两种方式任选一种：
   - **拖入素材**（没有整理好的订单文件夹时用）：填产品名称，点「新建订单」，然后把素材按类别拖进五个框——达人口播、达人动作、游戏录屏、口播文本（你发给达人读的脚本，.txt 或 .md）、官方素材（logo、截图也放这里）。至少要有一条达人口播。拖错了点文件右边的 × 移除。素材会复制到项目里的 `inbox` 文件夹，原文件不动；文件夹不能直接拖，请选中里面的文件。
   - **已有订单文件夹**：填完整路径（只读，不复制）。
3. 点「开始导入」。
4. 等它跑完三步（约 1–3 分钟，4K 视频会慢一点）：
   - 把素材转成竖屏、30 帧的工作副本；
   - 把达人口播转成文字；
   - 让 AI 给每个素材写一句描述。
5. 点「进入『素材』」。

> 订单文件夹**只读**，系统不会改它。工作副本放在 `public/derived/`，文字和记录放在 `projects/<项目名>/`。

**完成标志**：进入「① 素材」页，能看到所有素材的卡片。

### ① 素材：分类、核对、确认

目标：让每个素材都"有名字、有描述、归对了类"，并把口播文字校对准。

页面上有五个分类：文案、达人口播、达人动作、游戏录屏、官方素材。

1. **看分类对不对**。每张卡片有分类下拉框，错了就改。
2. **看描述对不对**。AI 写的描述有「AI 草稿」标记，你改过会变成「已人工修改」，AI 以后不会覆盖你改的内容。想让 AI 重写，点「AI 描述」。
3. **校对口播文案**（最重要）。在「文案」分类里，每条口播一张卡片，文字是电脑听出来的，可能有错：
   - 导入时放了口播文本的话，卡片上点「对照给达人的脚本」，脚本显示在下面，达人没读到的词标橙色，多说的词列在下面；
   - 点「听对应口播」，一边听一边改；
   - **只能改拼写，不能多词或少词**。字幕的时间是按词对齐的，词数变了系统会拒绝并提示；
   - 卡片下面会列出"和电脑听写相比你改了哪些词"，改动很大的会标红，防止不小心剪切粘贴弄乱了。
4. **全部点「确认」**。卡片多的话用「确认当前列表全部」。

**完成标志**：顶部显示"已确认 13 / 13"，页面提示「去『口播清理』→」。

### ② 口播：剪掉停顿、语气词、重说

目标：把达人说话时的"死气"去掉。

1. 点 **开始检测**，约 10 秒。
2. 每条口播会显示文字，下面标出要剪的地方：
   - ⏸ 红色的是**停顿**（句子之间停太久，会留 0.1 秒换气）；
   - 红色划线的字是**语气词、重复字、重说**；
   - 每一处旁边有 ▶ 可以试听，有「删掉」开关可以改成保留。
3. 觉得漏了口误，点 **AI 复核口误和重说**，AI 会再读一遍；你也可以直接点文字里的任意一个词，把它标成要删。
4. 核对完点 **确认清理**。

> 改了任何一处，都要重新点「确认清理」。

**完成标志**：顶部显示"口播从 X 秒缩到 Y 秒"，提示「去『方案』→」。

### ③ 方案：三个方向，选一套

目标：AI 先定三个**不同方向**的剪法，再各出一套方案；你比较后选一套。

**生成**

1. 页面顶部会检查四件事：口播已清理、素材已确认、模型可用、风格卡（可选）。哪一项不对，旁边有按钮直接跳过去。
2. 可以选一张**已确认**的风格卡。选了卡，三个方向里有一个会直接照卡来剪（标着蓝色的「照卡」），另外两个在开场、节奏、结构上和它不同；不选卡，三个方向都按快、中、慢三档节奏预设来剪。
3. 点 **生成方案**，等约 2 分钟。流程是：AI 定三个方向 → 每个方向出一套 → 程序检查（时长、重叠、插画占比、画面不能太久不变、推近模式、开头 2 秒达人出镜、结尾用结尾卡、禁止说法）→ 检查三套够不够不同，太像的那套会被要求重出。

**比较和修改**

每套方案是一张表，一行一句口播：

| 列 | 内容 | 你能做什么 |
| --- | --- | --- |
| 时间 | 这一句在成片里的位置 | 只看 |
| 口播内容 | 这一句说什么 | 只看（要改回「① 素材」） |
| 画面 | 这一句用什么画面 | 换素材、改全屏/画中画、改位置、改开始时间和时长、加或删镜头；没插画的行显示达人画面 |
| 效果 | 这一句的推近（不推近 100% / 轻推 110% / 推近 115% / 紧推 120%） | 直接改，每一句都由方案定好，没有"自动" |
| 字幕 | 这句话的每个词 | 点一个词，字幕里就高亮它 |

改过的行底色变黄，页面底部显示"改了 N 行，还没保存"：

- 点 **保存并更新这一套**，系统检查（不能超出这一句、两个镜头不能重叠、素材够长等），有问题会告诉你哪里不对，整次不保存；
- 想要品牌图标一直出现，勾上「常驻品牌图标」。

> 方案不带音效。

**选定**

选好一套，点 **选这一版 → 放进审阅精修**。如果审阅台里已经有你改过的方案，页面中间会弹出确认框：会生成新版本，字幕样式和主题会保留，上一个版本还能还原。点「继续」后要等约 1 分钟（生成预览和人脸检测），**请不要关闭页面**，做完自动跳到「④ 精修」。

**完成标志**：页面跳到「④ 精修」。

**想要几套都出剪映草稿？** 方案标签下面有「▸ 导出为剪映草稿（可多选）」：勾选几套，各生成一份剪映草稿，名字是「项目名 + 方案名」。用的是方案原样（不经过审阅台，字幕样式、主题是默认值），其中要精修的那套再单独选进审阅台。

### ④ 精修：最后的微调

目标：在真实预览里看一遍，把细节调好。

1. 左边是片段列表，中间是预览，右边是检查和参数。
2. 可以拖字幕框的位置、改字号颜色、调镜头；画面上红色标签是平台界面区（TikTok 文案区、右侧按钮、顶部标签），**字幕和文字不要放进这些区域**。
3. 每个片段可以标「保留 / 修改 / 放弃」，也可以写意见。
4. 所有改动自动保存成新版本，在「版本」里能看到，随时可以还原。
5. 画面上有"盖住人脸""超出安全区"的警告，按需要处理；全屏录屏碰到安全区是正常的，不用管。

**完成标志**：你看完整条，觉得可以交了。

### ⑤ 导出：出成片

**方式一：直接渲染成片**

1. 在「导出中心」确认文件名，点「开始导出视频」，约 5 分钟。
2. 程序会自动质检：规格（9:16、30 帧）、响度（-16 LUFS）、字幕时间、有没有空白或冻结的画面。
3. **质检通过只是及格线，一定要自己从头看一遍、听一遍。**

**方式二：导出剪映草稿，在剪映里再加工**

适合要加音效、背景音乐、贴纸等"调味"的订单（方案和草稿本身不带音效）。

1. 在导出中心的「剪映草稿」，点 **生成剪映草稿**。
2. 点 **放进剪映草稿箱**（系统会自动找到你的剪映草稿位置）。
3. 打开剪映，在草稿列表里找到它（没出现就关掉重开剪映），所有切点、字幕和录屏都已摆好，花几分钟微调后在剪映里导出。

多套方案想一次出草稿，在「③ 方案」里用「导出为剪映草稿（可多选）」。剪映正在运行时放不进草稿箱，草稿会生成，关掉剪映后到这里再「放进剪映草稿箱」即可。

> 草稿里的素材只是**指向本机文件的链接**。不要移动或改名 `public` 文件夹里的文件，否则剪映会提示"素材丢失"。

### 交付

把最终的 MP4 复制到订单的 `05_成品` 文件夹，按订单要求命名并提交。

## 3. 交付前自查清单

打勾再交：

- [ ] 画面是 **9:16 竖屏**，清晰（HD），没有模糊或马赛克
- [ ] 口播里**没有品牌不允许的说法**：不编造数字、评分、下载量、获奖；不提竞品，不做对比；不说电池、隐私、安全；没有诱导点击的箭头
- [ ] 字幕拼写正确，**位置不在平台文案区和右侧按钮区**
- [ ] 画面里没有违规内容（歧视、政治、毒品武器、成人内容、危险动作）
- [ ] 开头 2–3 秒就能抓住人（达人出镜、有钩子）
- [ ] 结尾有行动号召（例如"just get Kika"）
- [ ] 自己从头看了一遍，也听了一遍，音量正常、没有爆音
- [ ] 文件名符合订单要求，放进了 `05_成品`

## 4. 常见问题

| 现象 | 原因和办法 |
| --- | --- |
| 「生成方案」是灰的 | 看页面上的四项检查，哪项是红叉，点旁边的按钮去处理（素材没确认、口播没确认、没有 API Key） |
| 保存口播文案时提示"词数变了" | 字幕按词对齐，只能改拼写，不能增删词。点「还原」回到听写原文，再改 |
| 文案卡片上有红色的"→"提示 | 你的改动和听写差别很大，可能是剪切粘贴时弄乱了，仔细看一眼 |
| 方案上显示"过期" | 你在生成之后又改了素材、文案或口播清理。点「重新生成全部方案」 |
| AI 描述、生成方案失败，提示 401 | API Key 不对或过期，到「API 设置」重新保存并测试连接 |
| 页面改了没反应 | 关掉运行 `npm run desk` 的窗口，重新运行 |
| 剪映草稿箱里看不到刚放进去的草稿 | 关闭剪映再重新打开；还不行，看导出中心给出的草稿箱路径对不对 |
| 剪映提示素材丢失 | 工作副本被移动或改名了，不要动 `public` 文件夹 |
| 导出的视频没有音效 | 正常：方案不带音效，需要的话在剪映里加 |
| 点按钮没反应、提示 "No route" 或 "body too large" | 页面是新的，服务还是旧的：关掉运行 `npm run desk` 的窗口，重新运行 |
| 方案全部失败，日志里有 "forbidden claim" | 达人的原话里有品牌禁止的说法（夸大、评分、竞品、电池隐私安全等）。有品牌要求文件的订单会被拦下，没有的只给提示；这是原话，要让达人重录那一句，或在口播清理里标成删除 |
| 方案生成后又改了素材或口播 | 方案标"过期"，点「重新生成全部方案」 |
| 风格卡下拉框里没有我的卡 | 卡还是草稿：到风格库核对后点「确认并存入风格库」 |
| 拆解风格卡失败 | 红框里是原因，点 × 关掉；通常重新拆解一次就好。规则里出现了参考视频的产品名会被打回重写 |
| 追加了素材之后，之前确认的内容错位了 | 同一订单再追加录屏或官方素材时，素材编号可能因为文件名顺序改变；追加后回「① 素材」检查已确认的卡片 |
| 想回到之前的版本 | 在「④ 精修」的「版本」里选旧版本还原，旧版本不会丢 |

## 5. 术语对照

| 词 | 意思 |
| --- | --- |
| 达人 / 回片 | 拍视频的人 / 她发回来的原始视频 |
| 口播 | 达人对着镜头说话的片段 |
| 录屏 | 手机或软件的操作画面，用来盖在口播上，也叫插画 |
| 画中画 | 录屏变成小窗口，达人依然在画面里 |
| 风格卡 | 一条好视频的剪法说明书，可以反复用 |
| 口播清理 | 剪掉停顿、语气词、重说、口误 |
| 方案 | AI 给出的一个剪法版本，每个版本一张表 |
| 版本 | 审阅台里保存的每一次修改，随时可以还原 |
| 创意方向 | 一套方案的整体打法：开场怎么处理、节奏快慢、插画放哪、版式、推近方式。每次生成方案会定三个不同的方向 |
| 照卡 | 三个方向里直接用风格卡的方向和数字来剪的那一个 |
| 复现度 | 用参考视频自己的口播按风格卡出方案，和原视频比，插画位置和推近有多少一样 |
| 安全区 | TikTok 界面会盖住的位置（底部文案、右侧按钮、顶部标签），字幕要避开 |

## 6. 文件放在哪里（出问题时看这里）

| 内容 | 位置 |
| --- | --- |
| 订单原始素材 | 订单文件夹（只读，不要改） |
| 转好的工作副本 | `public/derived/<项目名>/` |
| 听写文字 | `public/transcripts/` |
| 项目记录（素材、清理、方案、审阅版本） | `projects/<项目名>/` |
| 风格卡 | `library/style-cards/`；参考视频的分析数据在 `library/references/`，拖进来的参考视频副本在 `library/references/_uploads/` |
| 拖入的订单素材 | `inbox/<订单名>/`（按订单文件夹的样子整理，原文件不动） |
| 方案的原始记录 | `projects/<项目名>/cut-script.a/b/c.json`（三个方向各一份）、`analysis/directions.json`（三个方向） |
| 剪映草稿 | `projects/<项目名>/exports/capcut/` |
| 渲染的成片 | 导出中心里显示的路径 |
| 出错日志 | `projects/<项目名>/logs/` |

更详细的说明：`docs/style-card.md`（风格卡）、`docs/voice-cleanup.md`（口播清理）、`docs/timeline-table.md`（表格方案）、`docs/capcut-export.md`（剪映草稿）。
